"Here's the definition I use."

The definition.

An AI-powered web app is a software product that combines the core components people already expect with the AI components that help them get something done.

Core components are the business features you've always expected: login, billing, a database, a dashboard, notifications.

AI components are the new part: an agent, voice, chat, automation, document search.

Put them together, and that's an AI-powered web app.

You already use them every day. Calendly, Netflix, Spotify, all AI-powered web apps.

"And the business half? It's not even new."

Web apps aren't new.

They've existed for decades, and you use them every day: Netflix, Spotify, Amazon, Uber, Google Docs, Canva.

They've even used AI for years, machine learning quietly making recommendations in the background. But that was predictive AI, and building it took specialized data science teams.

So what changed? Not the web app. The AI, and who can build it. Now, with generative AI like Claude and ChatGPT, any builder can add an intelligent layer, one that doesn't just predict, it creates, analyzes, and takes on work that used to need a person.

The foundation hasn't changed. The capabilities have.
