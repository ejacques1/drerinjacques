Video One

Build an AI Agent That Builds Websites

Five steps, all on your laptop. Ends with a tool you can start selling with — no deploying, no accounts, no paywall. Run it after every step so the agent visibly gains a new power each time.

1

Open an empty folder

VS Code
  1. File → Open Folder, make a new one called site-scout.
  2. Open the Claude Code panel.
  3. Everything from here is pasting prompts and clicking Approve.
≈ 2 min
2

Build the shell

Claude Code
Paste this

Set up a Next.js app with TypeScript called site-scout. Install @anthropic-ai/sdk and zod.

Create lib/agent.ts with a system prompt for an agent that helps web designers find local businesses without websites. Use model claude-opus-5. No tools yet.

Add .env.local with ANTHROPIC_API_KEY and APIFY_TOKEN.

Click Approve. Paste your two keys into .env.local — off camera.

The beat Run it. It talks, but it can't do anything. Say that out loud — this is the custom GPT everyone already has. Everything after this is what makes it an agent.
≈ 5 min
3

Give it the finder

Claude Code
Paste this

Add a tool called find_businesses that takes a business type and a town. It calls the Apify actor compass/crawler-google-places using APIFY_TOKEN, with this input:

{
  "searchStringsArray": ["dentist"],
  "locationQuery": "White Plains, NY",
  "website": "withoutWebsite",
  "maxCrawledPlacesPerSearch": 50,
  "maxReviews": 5
}

Return name, phone, address, hours, rating, category and the review text for each business.

Use the Tool Runner: betaZodTool from @anthropic-ai/sdk/helpers/beta/zod, run through client.beta.messages.toolRunner().

The beat Ask it for dentists in your town. Real businesses come back with real phone numbers. First moment it does something you couldn't do in a chat box.
Why this actor

Apify's store has purpose-named "businesses without websites" actors. Check ratings before trusting one — the obvious-sounding pick has 1.88 stars and 753 users. compass/crawler-google-places has 575,000 users, 4.70 stars, 36 million runs, and "website": "withoutWebsite" built into its input.

Set maxReviews. It defaults to 0, and the review text is what makes the generated sites good. Leave it off and every site loses its testimonials.

Phone comes standard. Email needs the paid contacts add-on — skip it. For a business with no website, the phone is the better channel anyway.

≈ 4 min
4

Give it eyes

Claude Code
Paste this

Add Anthropic's server-side web search tool — { type: "web_search_20260209", name: "web_search" } in the tools array.

Then add a custom tool read_page that fetches a URL and returns its text.

Update the system prompt so the agent researches each business it finds before doing anything else.

Slow down here. read_page is about twelve lines, and it's the whole idea: you describe a tool, and the agent decides when to use it. Nobody wrote logic saying "search now." Read the description out loud — that's the lesson your intro promised.

Make it build the sites

Claude Code
Paste this

The climax Run it on a real town. It grinds through business after business and finished websites start landing in the folder. Open one. This is the shot the whole video exists for — and the callback to the cold open.

Give every site a real link

  1. Vercel dashboard → Storage → Create → Blob.

Install @vercel/blob. Change save_site so instead of writing to /output it uploads each site with put() using public access, and returns the URL.

Put it online

The two ways to get paid

Camera

Now they've seen it work and they have one running. This is where the business talk lands.

Model 1 · you offer the service You're the web designer. The agent is your private tool. You sell websites to plumbers at $1,500 a job. No login, no payments, no support — you just need clients. Everything they need for this, they already built.
Model 2 · you sell the agent Your customers are other designers. They pay you monthly for access and go find their own clients. That means accounts, billing, support — a real product.

Then the handoff: "Model 1 you can start this week. Model 2 needs logins and payments, and that's what I walk through in the community."

Two things to say plainly, in both videos. The business data comes from public Google listings — against Google's terms, though not illegal. And the draft sites will get some details wrong, which is fine: "here's a draft, tell me what I missed" opens a conversation that a cold pitch never does.

On costs. A 50-business run is roughly 38¢ of Apify plus maybe 50¢ of API — under a dollar for eleven finished websites. The free Apify credit covers about a thousand places a month. Say the real numbers on camera; people assume this is expensive and it isn't.
