Get your Apify token

Browser
  1. Go to apify.com → Sign up. No credit card.
  2. You land in Apify Console.
  3. Click Settings in the left sidebar.
  4. Click API & Integrations.
  5. Click the copy icon next to your Personal API token.

Video One

Build an AI Agent That Builds Websites

Five steps. Runs on your laptop. Ends with a tool you can start selling with — no deploying, no accounts, no paywall.

1

Open an empty folder

VS Code
  1. File → Open Folder, make a new one called site-scout.
  2. Open the Codex panel from the sidebar.
  3. Set the mode dropdown to Agent.

Agent mode is what lets it create files and run commands. Chat mode is read-only and won't build anything.

≈ 2 min
2

Build the shell

Codex
Paste this

Set up a Next.js app with TypeScript called site-scout. Install the OpenAI Agents SDK (@openai/agents) and zod. Create an agent in lib/agent.ts with no tools yet — just instructions saying it helps web designers find local businesses that don't have websites. Add a .env.local with OPENAI_API_KEY and APIFY_TOKEN.

Click Approve when it asks. Paste your two keys into .env.local — off camera.

The beat Run it. It talks, but it can't do anything. Say that out loud — this is the custom GPT everyone already has. Everything after this is the difference.
≈ 5 min
3

Give it the finder

Codex
Paste this

Add a tool called find_businesses that takes a business type and a town. It should call the Apify actor code-node-tools/google-maps-businesses-without-websites using APIFY_TOKEN, and return the businesses with no website — name, phone, email, address, hours, rating, and reviews.

The beat Ask it for dentists in your town. Real businesses come back, with real phone numbers. First moment where it does something you couldn't do in a chat box.
≈ 4 min
4

Give it eyes

Codex
Paste this

Add OpenAI's built-in webSearchTool(), plus a custom tool called read_page that fetches a URL and returns its text. Update the instructions so the agent researches each business it finds before doing anything else.

This is the one to slow down on. read_page is about twelve lines, and it's the whole idea: you describe a tool, and the agent decides when to use it. Nobody wrote logic saying "search now." Read the description out loud.

≈ 5 min
5

Make it build the sites

Codex
Paste this

Add a tool called save_site that writes an HTML file to /output. Update the instructions: after researching each business, the agent writes a complete single-file website for them using their real name, services, hours, phone and address, with their actual Google reviews as testimonials. Use placeholder imagery, never their photos. Then save it.

The climax Run it on a real town. It grinds through business after business, and finished websites start landing in the folder. Open one. This is the shot the whole video exists for.
≈ 5 min

Video One ends here

Close on: "You've got a tool that makes websites for local businesses. That alone is a business — and that's the next video."

Video Two  ·  stands alone

How to Sell an AI Agent

Assume the viewer has never heard the word "agent" and has nothing built. Show it working before you explain anything, and name the money before you ask for four minutes of building.

1

Show the finished thing

Camera

No talking head, no definitions. A finished website for a real plumber, full screen, scrolling.

Say this "I have never spoken to this business. I don't know these people. This took ninety seconds and I didn't write a word of it."

They understand what an agent is by watching one work. Defining it first loses them.

0:00 — 0:30
2

Name it, then name the money

Camera

One sentence for what it is: something that finds local businesses with no website and builds each one a site.

Then show the folder — eleven finished websites, eleven phone numbers.

The hook "A web designer charges about $1,500 for one of these. There are eleven here. It cost me under a dollar to make them."

That number is why they stay. Say it before you ask them to build anything.

0:30 — 1:30
3

Build it fast

Codex

On camera: "If you've already got this running, skip to 4:00. If not, three minutes."

Paste Video One's five prompts merged into one. Fast-forward the install. Don't explain the tools here — that's Video One's job, and this viewer doesn't need it yet.

Never say "part two" No "like I showed last time," no "as you saw in the first video." Anyone landing here cold has a working agent by 4:00 and never feels behind.
1:30 — 4:00
4

Put a page on it

Codex
Paste this

Add a chat page at / with a box for business type and town. Stream the agent's progress so every step shows as it happens, and list the finished sites with links to open them.

Quick. It exists so a customer can use this without ever opening Codex.

≈ 3 min
5

Give every site a real link

Browser, then Codex
  1. Vercel dashboard → Storage → Create → Blob.
  2. Set it to Public. You can't change this later.
  3. Open the store's Projects tab → Connect to Project.
Then paste this

Install @vercel/blob. Change save_site so instead of writing to /output it uploads each site with put() using public access, and returns the URL.

Now each website has an address you can text to the owner. That's the whole difference between a folder on your laptop and something you can sell.

Why not a database Blob is already inside Vercel — no new account. 1GB is roughly 20,000 sites, and it's free.
≈ 4 min
6

Put it online

Browser
  1. github.com/new → name it site-scout → Private → Create.
  2. In Codex: "Push this to my GitHub repo site-scout."
  3. vercel.com/new → Import your repo.
  4. Open Environment Variables and add OPENAI_API_KEY and APIFY_TOKEN before deploying.
  5. Deploy. Live URL in about a minute.
Don't skip step 4 Your keys live on your laptop, not in the code. Deploy without them and the page loads but the agent fails. This is the most common thing that breaks here.
≈ 4 min
7

The two ways to get paid

Camera

Now they've seen it work and they have one running. This is where the business talk lands.

Model 1 · you offer the service You're the web designer. The agent is your private tool. You sell websites to plumbers at $1,500 a job. No login, no payments, no support — you just need clients. Everything they need for this, they already built.
Model 2 · you sell the agent Your customers are other designers. They pay you monthly for access and go find their own clients. That means accounts, billing, support — a real product.

Then the handoff: "Model 1 you can start this week. Model 2 needs logins and payments, and that's what I walk through in the community."

≈ 2 min

Two things to say plainly, in both videos. The business data comes from public Google listings — against Google's terms, though not illegal. And the draft sites will get details wrong, which is fine: "here's a draft, tell me what I missed" opens a conversation that a cold pitch never does.

On costs. Apify runs about 2¢ a lead and the free tier covers roughly 250 a month. OpenAI is the only thing you actually pay for, and a full run lands somewhere near 50¢. Say the real numbers — people assume this is expensive and it isn't.
