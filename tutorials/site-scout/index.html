One line to check

"More than 6 million" is defensible — current data puts roughly 27% of US small businesses without a website, which is closer to 9 million. But some sources say 17%, which lands just under 6 million.

Safer and stronger: "Roughly one in four small businesses in America still doesn't have a website." Better supported, and a fraction lands harder than a number that big.

Where it becomes an agent

For the intro — the through-line to name before you start building.

→

Step 5 is the moment

Steps 1–4 build something that talks. Useful, but it's the custom GPT everyone already has.

Step 5 is where it changes, and not because it gets a tool — because of how the tool is aimed. You don't tell it "run one search and stop." You tell it keep going until you have 10 businesses with no website. If a search comes back short it widens — a neighbouring town, a related category — and tries again.

One search with a limit of 10 is an automation. Deciding how to reach 10 is an agent. That's the whole distinction, and it's one line in a prompt.

Step 6 is where it gets proof of it. Given a business with four facts and no reviews, the agent found her specialty, her training, her languages, her full treatment list, and 19 reviews on a site nobody told it to check. Nobody wrote logic saying "search now" — it decided that was the next thing worth doing.

Video One

Build an AI Agent That Builds Websites

Seven steps. Runs on your laptop. No terminal anywhere. Ends with a folder of finished websites and the phone numbers to go with them.

1

Install Claude Code

VS Code
  1. Open VS Code. Free at code.visualstudio.com.
  2. Extensions tab in the left sidebar.
  3. Search Claude Code.
  4. Install, then sign in.

Two names, one setup — VS Code is the editor, Claude Code is an extension inside it. Worth separating out loud; people hear "Claude Code" and think it's a second app.

The extension brings everything with it. No terminal in this build.

≈ 2 min
2

Get an Apify token

apify.com
  1. apify.com → Sign up. Free, no credit card.
  2. Settings in the left sidebar.
  3. API & Integrations.
  4. Copy the Personal API token.

Apify is an app store for scrapers — thousands of small programs that go collect data from a site, built by other developers. You don't write one, you rent one per run.

Free plan is $5/month of credit. The scraper charges $0.004 a place, so that covers roughly a thousand businesses a month.

≈ 90 sec
3

Get an Anthropic key

console.anthropic.com

console.anthropic.com → API Keys → Create Key. Copy it — it's shown once.

This is the only thing in the build you pay for. A run of ten businesses lands around $1–2.

≈ 1 min
4

Set up the project

Claude Code

New empty folder in VS Code, open the Claude Code panel, paste:

Prompt

Set up a Next.js app with TypeScript called site-scout in this folder. Run npm install @anthropic-ai/sdk@latest zod — install the latest, don't write versions into package.json.

Create lib/agent.ts with a system prompt for an agent that helps web designers find local businesses without websites. Use model claude-opus-5. No tools yet.

Add .env.local with ANTHROPIC_API_KEY and APIFY_TOKEN.

Approve when it asks, then paste your two keys into .env.local.

Run it. It talks, and that's all it can do — no searching, no data, nothing outside the conversation.

Measured: 3 min 56 sec
5

Give it the finder

Claude Code
Prompt

Add a tool called find_businesses that takes a business type and a town. It calls the Apify actor compass/crawler-google-places using APIFY_TOKEN, with this input:

{
  "searchStringsArray": ["dentist"],
  "locationQuery": "White Plains, NY",
  "website": "withoutWebsite",
  "maxCrawledPlacesPerSearch": 10,
  "maxReviews": 10,
  "reviewsSort": "highestRanking"
}

Return name, phone, address, rating, category and review text for each business.

The agent's goal is a target, not one call: keep going until it has 10 businesses with no website. If a search comes back short, widen it — a neighbouring town, a related category, a larger limit — and try again. Stop at 10, or after 5 attempts.

Use the Tool Runner: betaZodTool from @anthropic-ai/sdk/helpers/beta/zod, run through client.beta.messages.toolRunner().

Run it and ask for dentists in your town. Real businesses come back, with real phone numbers — and if the first search is short, watch it widen and go again.

Picking the scraper

Apify has purpose-named "businesses without websites" actors. Check ratings first — the obvious-sounding one has 1.88 stars and 753 users. compass/crawler-google-places has 575,000 users, 4.70 stars, 36 million runs, and the no-website filter built into its input.

maxReviews defaults to 0. Leave it off and every generated site loses its testimonials.

≈ 4 min
6

Give it eyes

Claude Code
Prompt

Add Anthropic's server-side web search tool — { type: "web_search_20260209", name: "web_search" } in the tools array.

Then add a custom tool read_page that fetches a URL and returns its text.

Update the system prompt so the agent researches each business it finds before doing anything else.

read_page is about twelve lines. You describe what a tool does, and the agent decides when to use it.

This step is what makes the sites real. Apify finds who to build for; the search finds what to say. Skip it and you're generating templates with names swapped in.

≈ 5 min
7

Make it build the sites

Claude Code
Prompt

Add a tool save_site that writes an HTML file to /output.

After researching each business, the agent writes a complete single-file website using their real name, services, phone and address, with only 4-star-and-up reviews as testimonials. Placeholder imagery, never their photos. Omit hours rather than inventing them. If nothing verifiable exists for a section, leave the section out.

Also write output/index.html — a leads sheet listing every business with its phone number, category, and a link to the site you built them.

Set stream: true on the tool runner.

Run it on a real town. Open output/index.html — every business, every phone number, and a link to the site built for each one. Then open one of the sites.

stream: true or it crashes

max_tokens: 32000 without streaming throws "Streaming is required for operations that may take longer than 10 minutes." Hard stop, no output.

The two ways to get paid

By here they've seen it work and have one running. That's when pricing means something.

Model 1 · you offer the service You're the web designer. The agent is your private tool. You sell websites to plumbers at $1,500 a job. No login, no payments, no support — you just need clients. Everything they need for this, they already built.
Model 2 · you sell the agent Your customers are other designers. They pay you monthly for access and go find their own clients. That means accounts, billing, support — a real product.

Model 1 you can start this week with what you've already built. Model 2 needs logins and payments — that part lives in the community.

Two things worth being upfront about. The business data comes from public Google listings — against Google's terms, though not illegal. And the draft sites will get some details wrong, which is fine: "here's a draft, tell me what I missed" opens a conversation that a cold pitch never does.
