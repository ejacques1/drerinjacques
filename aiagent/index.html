First, what is an AI agent?

A normal AI chat waits for you to ask a question, then answers. An AI agent doesn't wait.

You give it a goal. It figures out the steps on its own, uses tools (searching the web, reading sources, writing files), checks its own work, and repeats until the job is done. You're not guiding each step. You set it loose and it runs.

A chatbot answers. An agent acts.

What you're building today.

A daily content agent. Every morning it finds the biggest AI news, picks the one story that matters most to your audience, and writes you three things: a LinkedIn post, an X thread, and a 60-second video script.

You wake up, the content's already written.

How it runs on its own (the cron job).

To make it run without you, you deploy it to Vercel and give it a schedule, called a cron job.

Think of a cron job as an alarm clock for your agent: at 6am every day, Vercel wakes it up in the cloud and tells it to run, whether you're awake or not.

A tool is something you run. An agent runs itself.

Troubleshoot & FAQ

What's the difference between this and a normal AI chat?
A chat waits for you to ask, then answers one thing. An agent takes a goal and runs the whole job itself, searching, deciding, writing, checking, on a loop, without you steering each step. This one does that every morning on a schedule.
Why does my API key go in two places?
The .env file is for runs on your computer. Vercel is a separate machine in the cloud, so it needs its own copy of the key in Settings → Environment Variables to run the 6am job without you. Add it in both. If you add it to Vercel after deploying, redeploy so it takes effect.
My first run failed with an API key or billing error
This is almost always the key. Make sure it's a real key from console.anthropic.com and that you've added a payment method there. A key with no card on file will fail on the first run.
What is a cron job?
A cron job is just a schedule. It's the alarm clock that tells Vercel "run this agent at 6am every day." That one line in vercel.json is what makes it run on its own.
What is Node.js, and why do I need it?
Node.js is the software that lets code run directly on your computer instead of only inside a web browser. The Agent SDK and the Vercel tools are built on it, so it's the engine everything here needs. Install it before you start.
How much does it actually cost?
About a dollar or two per run, because the agent searches, reads sources, and writes three pieces. Daily, that's roughly $30–60 a month. Watch it the first week, and if that's more than you want, tell Claude to change the schedule (say, three mornings a week instead of seven).
Claude keeps asking me to approve things
That's normal and safe. Say Yes / Approve to everything so it can keep working.
It says a command is "not recognized" or "not found"
Tell Claude: "Restart the terminal and try again." This usually happens right after it installs something new, and a quick restart fixes it.
