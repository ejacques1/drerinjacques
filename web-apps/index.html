The two kinds of components

What's in the app.

Core components

What every app needs, AI or not. These are what make it sellable.

  • Authenticationthe login
  • Databasewhere everything is stored
  • Billingyour Stripe connection
  • File uploads
  • Notificationsemail and Slack

  • Admin panelyour view of what users are doing

AI components

What makes it intelligent. These are what people pay for.

  • Agentsdecide their own steps to get a job done
  • Automationsrun a fixed path you designed
  • Chat interfaceconversational front end
  • Voice interfacea phone number that answers, takes intake, books appointments
Where the money is

They're not paying for software.

Your customer isn't paying for software. They're paying for work to get done.

Anything a human used to have to do, an agent can do now. Which means the agent goes behind the paywall. The app collects and charges. The agent delivers.

  • Resume service: an agent that reads the upload and writes the evaluation
  • Coaching offer: an agent that turns intake answers into a client action plan
  • Directory: an agent that interviews the visitor and matches them to the right listing
  • Learning platform: an agent that reviews student work and gives feedback
  • Contract review: an agent that reads the document and flags the risks
  • Website audit: an agent that crawls the site and lists what to fix
The work becomes the agent. The app is how you get paid for it.
The question to ask

Not "what are you building."

That gets you nowhere. Ask instead:

Which components does your app have, and which is it missing? Someone with an agent and no billing doesn't have a business. The component list becomes a checklist.

And to find your agent:

What do you currently do for clients that you're tired of doing yourself? That's your agent. A better question than asking you to imagine one from nothing.
